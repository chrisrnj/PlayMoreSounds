6.0 - Complete rewrite of the plugin.

- Added Random option at the start of sound lists. Enable it for a random sound to be selected from the sound list. If you'd like for multiple sounds to be selected at once, create sound groups by naming the sections with the same prefix, separating the prefix with a dot, like so:

Join Server:
  Enabled: true
  Random: true
  Sounds:
    '1.1':
      Sound: BLOCK_NOTE_BLOCK_PLING
    '1.2':
      Sound: BLOCK_NOTE_BLOCK_BASS
    '1.3':
      Sound: BLOCK_NOTE_BLOCK_DIDGERIDOO
    '2.1':
      Sound: ENTITY_FIREWORK_ROCKET_BLAST
    '2.2':
      Sound: ENTITY_FIREWORK_ROCKET_LAUNCH
    '2.2':
      Sound: ENTITY_FIREWORK_ROCKET_SHOOT

Prefix 1 or 2 both have a 50% chance of being selected. If prefix 1 is selected, then sounds 1.1, 1.2 and 1.3 will be played simultaneously, same thing for prefix 2.

- Added WORLD_LOCAL radius: sounds with this radius option will be played for every player in the world, but at the location of the source. This means that only players that get near the sound location will be able to hear it.

- Added independent sound names for all current versions of Minecraft starting from 1.7.

- Added back Relative Position option for sounds.

- Several features of PlayMoreSounds 5.0 are missing as I rewrite them. Right now the plugin has no support for specific event scenarios like specific commands, chat messages, death types, region entering, etc. The only configuration that's currently supported is sounds.yml, and there are no commands or GUI editors available.

- Sounds will now have an emitter specified, and follow this emitter around as they move. Allowing for long sounds to be played independent of location and world.

- The plugin now uses Kyori Adventure API, this means that PaperMC (or a fork) is required to run the plugin.

- The sound playing class is now independent of platform. This means that it's going to be easier to port the plugin for other modding platforms like Sponge or Fabric.

- Update to make use of EpicPluginLib version 3.0.
